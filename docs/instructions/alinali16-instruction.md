# Как отправить отложенное сообщение в Telegram

1. Откройте нужный чат (личный диалог, группа или канал).
2. Напишите сообщение.
3. Открыть меню отправки сообщения:

* **Для компьютера:** Нажмите правой кнопкой мыши на кнопку «Отправить».
* **Для телефона:** Удерживайте кнопку отправки до появления меню.

4. В появившемся меню выберите «Отправить позже».
5. Укажите дату и время отправки.
6. Подтвердите действие.
