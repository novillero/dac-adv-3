# Секретные чаты Telegram для iOS

## Введение

Секретные чаты в Telegram — это функция для безопасного обмена сообщениями, которая использует сквозное шифрование. Благодаря этой функции сообщения шифруются на устройстве отправителя и расшифроваются только на устройстве получателя.

Основное отличие секретных чатов от обычных заключается в том, что они не синхронизируются с облаком Telegram. Доступ к таким чатам возможен только на том устройстве, где они были созданы.

Секретные чаты подойдут для ситуаций, когда важно обеспечить максимальную приватность переписки, например:

- Передача конфиденциальной информации.
- Обмен личными данными.
- Временные обсуждения, не требующие сохранения истории.

Благодаря дополнительным функциям, таким как таймер удаления сообщений и уведомление о создании скриншотов, секретные чаты предоставляют пользователям полный контроль над приватностью общения.

## Особенности работы секретных чатов

Секретные чаты Telegram отличаются от обычных чатов рядом технических и функциональных особенностей, направленных на приватность и безопасность.

**Основные особенности:**

- Сквозное шифрование. Все сообщения защищены методом сквозного шифрования. Сообщения шифруются на устройстве отправителя и расшифровываются только на устройстве получателя. Это делает невозможным перехват данных третьими лицами.  
- Отсутствие синхронизации с облаком. Секретные чаты не хранятся на серверах Telegram и не синхронизируются между устройствами. Доступ к чату возможен только на том устройстве, где он был создан.  
- Уведомление о скриншотах. При попытке сделать скриншот в секретном чате появляется уведомление, а на скриншоте не отображаются сообщения чата.

**Ограничения:**

- Нет синхронизации между устройствами. Вы можете использовать секретный чат только на том устройстве, на котором он был создан.  
- Ограниченное число участников. Секретные чаты поддерживают только общение не более двух пользователей.  
- Отсутствие некоторых функций мессенджера. В сообщениях секретного чата нельзя оставлять реакции и закреплять сообщения.  
- Ограничения управления чатами. Невозможно закреплять чат и перемещать в папки.

## Особые возможности секретных чатов

Секретные чаты Telegram предоставляют пользователям уникальные инструменты для обеспечения конфиденциальности общения:

- **Таймер удаления сообщений.** Сообщения могут автоматически удаляться через заданное время после их прочтения. Таймер позволяет устанавливать срок хранения сообщений.  
- **Запрет на пересылку сообщений.** Сообщения в секретных чатах нельзя пересылать другим пользователям, что предотвращает их случайное или намеренное распространение.  
- **Уведомление о создании скриншотов.** Telegram уведомляет пользователей о создании скриншота в секретном чате, а сообщения не отображаются на скриншоте.  
- **Проверка безопасности соединения.** Для уверенности в защите чата пользователи могут сравнить ключи шифрования на своих устройствах. Совпадение ключей подтверждает, что соединение защищено.

## Инструкции по работе с секретными чатами

### Как начать секретный чат

Создание нового секретного чата для безопасного общения с пользователем.

**Порядок действий:**

1. Перейдите на вкладку *Чаты*.  
2. Выберите чат с пользователем.
3. В открывшемся чате нажмите на аватар пользователя вверху экрана.
4. В открывшемся профиле пользователя нажмите **ещё**.
5. Выберите *Начать секретный чат*.

Теперь весь обмен сообщениями с выбранным контактом будет в защищенном секретном чате с шифрованием.

### Как включить таймер удаления сообщений

Настройка автоматического удаления отправленных сообщений через заданное время после их прочтения.

Убедитесь, что вы находитесь в секретном чате.

**Порядок действий:**

1. Нажмите **Автоматическое удаление** в нижней части экрана.
2. В открывшемся списке выберите время, через которое сообщения должны быть автоматически удалены.
3. Подтвердите выбор, нажав **Готово**.

Теперь все отправленные сообщения в этом чате будут автоматически удаляться через установленное вами время после того, как они будут прочитаны получателем.

### Как проверить безопасность секретного чата

Проверка целостности и безопасности соединения в секретном чате для уверенности в его защищенности.

Убедитесь, что вы находитесь в секретном чате.

**Порядок действий:**

1. Нажмите на аватар пользователя вверху экрана. Откроется профиль пользователя.  
2. Нажмите **Ключ шифрования**.
3. В открывшейся вкладке отобразится изображение и текст ключа шифрования.
4. Сравните отображаемый ключ шифрования с ключом на устройстве вашего собеседника.
   - Если оба ключа совпадают, соединение защищено.
   - Если ключи различаются, это может указывать на возможное нарушение безопасности.

Если ключи шифрования совпадают, соединение является безопасным, и вы можете продолжать общение с уверенностью в защите переписки.

### Как завершить секретный чат

Завершение секретного чата и удаление всей истории переписки на обоих устройствах.

Секретный чат должен быть создан ранее.

**Порядок действий:**

1. Перейдите на вкладку *Чаты*.  
2. Смахните влево секретный чат, который хотите завершить.  
3. Нажмите **Удалить**.
4. Нажмите **Удалить у меня и пользователя**.

***Примечание:*** вы можете отменить удаление секретного чата в течение 5 секунд. Для этого нажмите **Отмена** в появившемся окне в нижней части экрана.

***Важно:*** При выходе из учётной записи все созданные секретные чаты удаляются.

Секретный чат будет завершен, и все сообщения будут удалены. Чат исчезнет из вашего списка, и восстановить его будет невозможно.

### Включение секретных чатов в Telegram для Windows

Активирование секретных чатов в версии Telegram для Windows.

**Проверьте:**

- Установлена последняя версия Telegram для Windows.  
- Для работы с секретными чатами нужен конфигурационный файл с соответствующими параметрами.

**Порядок действий**:

1. Перейдите в папку, в которую установлен Telegram. По умолчанию, путь к папке: ***C:\\Program Files\\Telegram Desktop\\***.  
2. Откройте конфигурационный файл ***config.ini***. Если файл отсутствует, создайте его.  
3. Вставьте в файл параметры для активации секретных чатов:

    ```
    secretChatsEnabled: true maxSecretChatDuration: 60 disableScreenshotWarning: false
    ```

4. Сохраните изменения в файле и закройте его.  
5. Перезапустите Telegram, чтобы изменения вступили в силу.  
6. После перезапуска откройте *Настройки → Продвинутые настройки* и убедитесь, что опция *Секретные чаты* активирована. Если она появилась, значит, функция успешно включена.

Теперь секретные чаты будут доступными в версии Telegram для Windows. Вы можете создавать и использовать секретные чаты точно так же, как в мобильной версии.
