# Создание папки с чатами в Telegram (Инструкция для ПК)

## Шаг 1. Создание новой папки
1. Откройте приложение Telegram на компьютере.

2. Нажмите на три горизонтальные линии (меню) в левом верхнем углу.

3. Выберите пункт меню **«Настройки/Settings»**.

4. В окне списка настроек нажмите **«Папки/Chat Folders»**.

5. Нажмите кнопку **«Создать папку/+ Create New Folder»**.

6. Введите имя папки (например, «Коллеги», «Подписки», «Семья»). Максимальная длина названия — 32 символа. 

7. Нажмите **«Добавить чаты/Add Chats»** и добавьте чаты одним из способов, описанным ниже.


## Шаг 2. Настройка содержимого папки (три способа)
Система предложит вам выбрать, какие чаты попадут в эту папку. Вы можете комбинировать следующие методы.

### Способ А: Выбор вручную

Нажмите **«Добавить чаты/Add Chats»**.

Отметьте галочками нужные диалоги из списка.

Нажмите галочку в нижнем углу для сохранения.

### Способ Б: Автоматическое добавление по типам чатов

Включите переключатели для соответствующих категорий:

* «Контакты/Contacts» (люди из вашей адресной книги)

* «Не контакты/Non-Contacts»

* «Группы/Groups»

* «Каналы/Channels»

* «Боты/Bots»

### Способ В: Фильтрация по ключевым словам

1. В разделе **«Включить сообщения/Included Chats»** в поле поиска введите слово или фразу. 
2. В списке отобразятся чаты, в названии которых содержится это слово.
3. Выделите чаты.
4. Нажмите галочку для сохранения.


## Шаг 3. Исключение чатов (опционально)
Если вы хотите исключить определённые чаты, нажмите **«Исключить чаты/Excluded Chats»** и выберите их из списка.

## Шаг 4. Сохранение и проверка
Нажмите галочку в правом нижнем углу для сохранения.

Вернитесь на главный экран списка чатов. Теперь в верхней части экрана вы увидите строку с именами ваших папок. По умолчанию активна папка **«Все чаты/All»**.

Нажмите на название созданной папки — Telegram отобразит только те диалоги, которые вы добавили или попадают под заданные правила.

## Удаление папки
В разделе **«Папки/Chat Folders»** выберите папку, нажмите на три точки слева и выберите **Delete**.
Подтвердите удаление.
