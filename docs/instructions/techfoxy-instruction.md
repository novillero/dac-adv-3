# Как отправить отложенное сообщение в Telegram

## 1. Откройте нужный чат

Перейдите в личные сообщения, группу или канал, куда нужно отправить сообщение позже.

## 2. Напишите сообщение

Введите текст сообщения, которое хотите отправить с задержкой.

## 3. Откройте меню отправки

Нажмите и удерживайте кнопку отправки сообщения:

    - **Android** — удерживайте кнопку с иконкой самолетика.
  
    - **iPhone** — удерживайте кнопку отправки.
  
    - **Desktop/Web** — нажмите правой кнопкой мыши или удерживайте кнопку отправки.

## 4. Выберите пункт «Отправить позже»

В появившемся меню вам будут предоставлены следующие возможности:

    - **Отправить без звука**.
  
    - **Отправить позже**.
  
    - **Когда будет в сети**.

Выберите `Отправить позже`.

## 5. Укажите дату и время

Введите:

    - Дату отправки.
  
    - Время отправки.

Ниже можно настроить систематическое отправление сообщения *(функция доступна только пользователям **Telegram Premium**)*:
- Повторять:`Ваше время`

После этого подтвердите действие кнопкой `Отправить [дата и время]`.

## 6. Проверьте отложенное сообщение

Сообщение появится в отдельном разделе отложенных сообщений. Его можно:

    - Изменить.
  
    - Удалить.
  
    - Отправить сразу.
  
    - Перенести на другое время.
